# Workflows

**Model paths are portable.** Each workflow's `models:` section names model files by bare filename (e.g. `path: gemma-4-e2b-it-Q8_0.gguf`), not an absolute path. Agency resolves them against `AGENCY_MODELS_DIRS` (a colon-separated, ordered directory list; element 0 is primary, default `~/.llama-cpp/models`) and auto-starts a local llama.cpp server when the declared endpoint is unreachable. Configure your model locations in a local `.env` (see `.env.example`) — put the `.gguf` files in any listed directory and the workflows run unchanged.
